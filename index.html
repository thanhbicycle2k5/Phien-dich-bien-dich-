Hãy đặt tên chủ đề để lưu và tìm lại tài liệu của bạn.

Cài đặt DeepL API

Cách lấy API Key miễn phí

  1. Đăng ký tài khoản DeepL API; ở bước chọn gói, chọn DeepL API Free (không phải gói DeepL Pro dành cho dịch trên website).
  2. Xác nhận tài khoản theo hướng dẫn của DeepL, sau đó mở phần quản lý tài khoản và tìm mục API Keys hoặc Authentication Key.
  3. Sao chép Authentication Key, dán vào ô phía trên và bấm Lưu key.
  4. Đóng cửa sổ này, chọn Tài liệu cá nhân, rồi đặt Chiều dịch theo văn bản của bạn trước khi bấm kiểm tra.

Key dùng được cho cả hai chiều, không cần chọn ngôn ngữ đích khi tạo key. Ứng dụng tự gửi ngôn ngữ nguồn và đích theo lựa chọn: Tiếng Việt → Tiếng Anh hoặc Tiếng Anh → Tiếng Việt.

Bạn có thể dùng DeepL để nhận gợi ý cho tài liệu cá nhân.
